## 核心循环

玩家通过**轻击牵制 + 蓄力输出**的资源循环,在 boss 攻击间隙找到部位破坏窗口,多次破坏关键部位后接触核心,最终击败 boss。

### 玩家动作(4 个)

- **轻击**: 出手迅速 + 借击 dash 位移 + **格挡 boss 攻击** + 攒能量 + **不造成伤害**
- **蓄力**: 前摇长(易被打断)+ 消耗能量 + **唯一伤害源** + 破坏部位
- **格挡**: 帧窗口判定
- **位移**: 轻击自带 dash

### Boss 部位系统

- 4 部位(头 / 躯干 / 腿 1 / 腿 2)+ 1 核心
- 部位独立血量
- 关键部位血 0 → mesh 隐藏 + **核心可被打**
- 核心血 0 → boss 死亡

### 战斗循环

1. 玩家轻击(攒能量 + 牵制)
2. boss 攻击 → 玩家格挡 / 位移
3. 玩家蓄力(消耗能量 + 扣 boss 部位血,前摇可能被 boss 攻击)
4. 重复 1-3,关键部位血 0 → 标记破坏
5. 蓄力打核心
6. 核心血 0 → 胜利

1. **玩家**: 血量 UI + 能量条 UI + 轻击(格挡 + 攒能量 + 不伤害)+ 蓄力(消耗能量 + 扣 boss 部位血)

## 实现思路(5 模块 / 3 阶段)

**5 模块**:
1. 玩家状态机 — 枚举 + 动画蓝图
2. 数据驱动 — 数值外置(DataAsset / DataTable)
3. 玩家能力 — 4 输入各对应 BP 函数
4. Boss 部位 — 4 子组件 + 独立血量 + 命中检测
5. 战斗循环(GameMode)— 全局状态读写

**3 阶段顺序**:
| 阶段 | 内容 | 时长 |
|---|---|---|
| 1 | 砍模板 + 数据驱动 + 玩家血量 UI | 1-2h |
| 2 | 轻击 + 蓄力 + 能量条 UI | 2-3h |
| 3 | Boss 部位系统 + 战斗循环测试 | 2-3h |
