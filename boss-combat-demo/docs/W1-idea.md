## 核心体验(一句话)

**通过轻击牵制 + 蓄力爆发的资源循环,在互相过招牵制中找到部位破坏的输出窗口,体验"每次攻击都关键"的紧张战斗。**

---

## 战斗核心 3 要素

1. **资源循环**: 轻击攒能量 → 蓄力消耗能量(高伤害,可能挨打)
2. **部位破坏**: 蓄力是破部位关键,破后 → **大硬直 + 恢复能量** → 输出窗口
3. **容错**: 玩家有多血(可挨几次打),但失误太多会死

**互相过招牵制的体现**:
- 轻击的"牵制": 在 boss 攻击间隙打轻击,不只是打伤害,是为蓄力做准备
- 蓄力的"过招": 蓄力时自己处于危险(boss 攻击可能打断),boss 也在攻击
- 部位破坏的"奖励": 破部位后,大硬直让玩家有输出窗口 + 恢复能量
- 容错的"再战": 玩家挨打不死,可以"失误后恢复",但失误太多会死

### 玩家动作(4 个核心)

- **轻击**: 攒能量 + 扣少量 boss 部位血
- **蓄力**: 消耗能量 + 高伤害 + 前摇(可能挨打)
- **翻滚**: 躲 boss 攻击
- **格挡**: 防 boss 攻击(待定细节)

### boss

| 属性 | 占位值 | 备注 |

| 部位血量 | 30/部位 | 双层独立血 |
| 核心血量 | 100 | 破关键部位后才能打 |
| 攻击模式 | 3D 实时 + 读招 | 跟玩家对等 |

### 蓄力 / 硬直(占位)

## 跟传统 1v1 boss 战的差异

| 标杆 | 血量 | 节奏 | 关键机制 |
|---|---|---|---|
| 魂系列 | 多血 | 慢 | 翻滚无敌帧 + 耐力 |
| 空洞骑士 | 多血 | 中 | 下劈 + 冲刺 + 多次攻击 |
| 哈迪斯 | 多血 | 快 | 连招 + 神力 + 肉鸽 |
| 怪猎 | 多血 | 中 | 部位破坏 + 蓄力 + 多人 |
| 只狼 | 多血(架势) | 中 | 完美格挡 + 一击致命 |
| 武士零 | 一击必死 | 快 | 闪避 + 慢动作 + 即时反馈 |
| **本 demo** | 中等容错 | 中 | **资源循环 + 部位破坏 + 蓄力爆发** |

**反常识强度**:
- 跟怪猎: 怪猎**任何部位都掉总血**;这里是**双层独立血 + 资源循环**
- 跟传统: 传统**直接打血条**;这里是**先打外层,才能打内层 + 能量管理**
- 跟武士零: 武士零**1 击必死**;这里是**资源循环 + 容错**
- 3D 实时 + 资源循环 + 部位破坏 — 玩法独特
