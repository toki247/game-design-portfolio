## 1. 核心体验(已定)

通过三消发动技能,击败敌人并领取奖励,进而强化或改变技能的游戏。
核心体验 = 三消的简单易上手策略性 + 快速爽感,结合肉鸽的随机性和成长感。

## 2. 核心机制(已定)

- 三种颜色方块 = 1 角色的三个技能(每技能对应一种颜色)
- 消除数量多少定技能效果强度
- 玩家回合固定行动次数,单次交换消耗 1 点(无效交换回滚不消耗,连锁消除免费),归 0 切敌方回合,双方循环
- 肉鸽层 a+c:局内 build 随机 + 局内地图/事件随机
- 策略性主要在肉鸽玩法上体现

## 3. 范围(W2 规则定稿,数字待 W3)

> 规则部分已定稿。数字部分(各档伤害/护甲/增幅% / 减伤% / MP 数值等)走 JSON 配置,W3 填。

### 3.1 棋盘
- 10 列 × 4 行(可配)
- 横向重力:新方块**左侧补**,旧方块**往右掉**
- 3 色方块:棕(挥砍) / 白(护甲) / 黑(增幅)

### 3.2 回合与行动
- 一回合 6 行动(可配)
- 每次行动 = 1 次交换(4 方向:上/下/左/右)
- **无效交换不消耗行动**(必须形成消除,否则回滚)
- **连锁消除免费**(消除后补充的方块若自动消除,不消耗行动)

### 3.3 消除规则(7 种形式,统一按 N 块映射,无形状特殊效果)
- 3/4/5 个同色行/列 → 3/4/5 消效果
- 2x2 同色 → 4 块(按 4 消效果)
- L 型(3+2 同色,附加 2 个连接)→ 5 块(按 5 消效果)
- 2x3 / 3x2 → 6 块(按 6+ 块效果)
- 7+ 块复杂形状 → 6+ 块效果
- 6+ 块 = 5 块效果 × 系数(每多 1 块 +20%,系数可配)

### 3.4 技能机制

**棕色(挥砍)** → 攻击 + 攒 MP
- 3/4/5 块:伤害 + MP 都按档位提升
- 6+ 块 = 5 块效果 × 系数

**白色(护甲)** → 护甲 + 自身减伤
- 3 块:护甲
- 4 块:护甲 + 5% 减伤
- 5 块:护甲 + 10% 减伤
- 6+ 块 = 5 块效果 × 系数
- 减伤 buff **多次消除取最大值覆盖**

**黑色(增幅)** → 增幅 buff
- 3/4/5/6+ 块 → 增幅 I/II/III / 6+ 系数
- 增幅 I/II/III 影响**棕伤害 + 白护甲**
- **不影响**:减伤率、MP 获取
- 肉鸽构筑可加"强化 0%"等占位设计

### 3.5 增幅 buff 行为
- **FIFO 队列**:多次消除黑色叠加,使用时优先消耗先产生的
- **跨回合保留**:直到消耗
- **消耗时机**:使用**其他颜色**(棕/白)消除时消耗队首
- **消耗 5 MP**:消除黑色后若 MP ≥ 5,自动消耗,获得**第 2 个 buff**(同档位,按时间入队)
- 强化默认触发(MP ≥ 5 → 下次消除黑色时自动消耗 5 MP)

### 3.6 角色(魔剑士,基于魔力的职业)
- MP 上限 10(可配)
- 通过攻击(棕色)积攒魔力
- 魔力到一定值消耗以强化其他技能(通过黑色辐射)

### 3.7 可配字段清单(全部走 JSON,数字待 W3)
- **战斗循环**:棋盘行/列、行动次数
- **角色**:MP 上限、MP ≥ 5 阈值、护甲硬封顶(默认 99999)
- **棕 N 块**:伤害 X_N、MP Y_N(N = 3,4,5,6+)
- **白 N 块**:护甲 Z_N、减伤%(4 块 5%、5 块 10%)
- **黑 N 块**:增幅 I/II/III %(影响棕/白)、6+ 系数
- **6+ 块规则**:每多 1 块 +20% 系数(可配)
- **公式档位**:数值表(默认,档 1)

### 4.3 角色属性

> 通用字段表,支持多角色(玩家 / 敌人 / 未来 NPC)。所有数值字段都通过 JSON 注入,详见后续"配置参考文档"。

#### 角色 (Character)

| 字段 | 类型 | 说明 |
|---|---|---|
| id | str | 唯一标识 |
| name | str | 角色名 |
| type | enum | `player` / `enemy` |
| hp / hp_max | int | 当前/最大血量 |
| ap / ap_max | int | 当前/最大行动点 |
| resources | dict[str, Resource] | 资源槽(MP/能量/...) |
| buff_queue | list[Buff] | FIFO buff 队列 |
| armor | int | 护甲值(独立,跨回合) |
| damage_reduction | int | 当前减伤 % |
| skills | list[Skill] | 技能列表 |
| ai_behavior | AIBehavior? | 敌人 AI(玩家 None) |

#### 资源 (Resource)

| 字段 | 类型 | 说明 |
|---|---|---|
| name | str | 资源名(MP/能量/...) |
| current | int | 当前值 |
| max | int | 上限 |
| regen_per_turn | int | 每回合自动恢复(默认 0) |
| **carry_over** | bool | 跨回合是否保留(默认 true) |

### 4.4 技能系统

> 数据式驱动(JSON 注入),支持多颜色 / 多效果 / 多档位。

#### 技能 (Skill)

| 字段 | 类型 | 说明 |
|---|---|---|
| id | str | 唯一标识 |
| name | str | 技能名 |
| color | enum | `brown` / `white` / `black` / ... |
| effects_by_count | dict[int, list[Effect]] | 消除数 → 效果列表 |
| extra_block_rule | struct | 6+ 块规则(系数 + 公式) |

#### 效果 (Effect)

| 字段 | 类型 | 说明 |
|---|---|---|
| type | enum | `damage` / `armor` / `buff` / `heal` / `dot` / ... |
| target | enum | `self` / `enemy` / `all` |
| params | dict | 数值参数(可配) |

#### buff (Buff)

| 字段 | 类型 | 说明 |
|---|---|---|
| id | str | 唯一标识 |
| type | enum | `amplify` / `reduction` / `dot` / `regen` / ... |
| value | float | 数值 |
| duration | enum | `permanent` / N 回合 |
| **stack_rule** | enum | `queue` / `max` / `sum` / `replace` |
| **max_stacks** | int? | 最大叠加数(可选) |
| **carry_over** | bool | 跨回合是否保留(默认 true) |
| trigger | enum | 触发条件 |
| source | str | 来源标识 |
