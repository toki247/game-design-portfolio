## 主角设定(2026-08-21 14:20)

- **兄妹**: 经营**魔物餐馆**的兄妹(主角就是餐馆老板)
- **动力**: 餐馆需要食材 + 赚钱
- **循环**:
  1. 进迷宫搜索宝藏
  2. 狩猎魔物
  3. 把魔物处理成食材
  4. 在餐馆做成料理
  5. 售卖 → 赚钱 → 进更深迷宫

> 这跟"普通冒险者 → 卖给餐馆"产业链不同 — 主角**就是餐馆经营者**,自己进迷宫找食材。战斗 + 烹饪双线循环。

## 核心玩法(2026-08-21 14:53)

两块玩法,产出**互相转化**(双线循环):

### 1. 餐厅经营

- **产出**: 赚钱
- **投入**: 买装备 / 招募冒险者 / 学习技能 → **强化迷宫探索**

### 2. 迷宫探索

- **产出**: 食材(魔物) + 宝藏 + 新菜单(开发)
- **投入**: 餐厅赚钱 → **开发新菜单**(食材 + 收入)

> 餐厅赚钱 → 强化迷宫(装备/招人/学技能) → 迷宫带回更多食材 + 宝藏 → 餐厅开发新菜单 → 赚更多钱。
> 这是个**正反馈循环**,核心驱动力。

## 玩法框架(2026-08-21 16:03)

### 1. 餐厅经营

- 用**食材**按**菜谱比例**制作
- 越**珍贵食材** + 越**高级餐点** = 更好价格

### 2. 迷宫探索(分层,以撒式)

- **分层**: 每层迷宫有多个房间
- **结构**: 从起始房间开始 → 找通往下层的入口
- **房间事件**: 宝藏 / 战斗 / 等等

### 3. 战斗玩法

- **类型**: **空之轨迹的类战棋**(回合制 + 位置 + 技能组合)
- 迷宫里发生战斗时,进入战棋界面

> 注: 空之轨迹具体机制(S-Craft / AT 奖励 / 行动顺序 等)属于具体系统层级,等展开时再写。

## 3 个大循环梳理(2026-08-21 16:58)

### 1. 餐厅循环(单系统)

```
[库存] → [食谱] → [烹饪] → [售卖] → 钱
   ↑                                    ↓
   └────── [员工系统 / 店铺升级] ←─────┘
```

**驱动力**: 食材(从迷宫带回)+ 员工效率 → 卖更多

### 2. 迷宫循环(单系统)

```
[进迷宫] → [战斗 + 探索] → [收集 + 掉落] → [撤退 / 继续]
   ↑                                                ↓
   └────── [临时道具 / 祝福(Buff)] ←───────────────┘
```

**驱动力**: 战斗胜利 + 临时反馈(永久成长在迷宫外)

### 3. 核心循环(跨系统,餐厅 ↔ 迷宫)

```
[餐厅赚钱] ── 投入 ──→ [养成系统](技能 / 装备 / 职业)
     ↑                              ↓
     │                        [进迷宫变强]
     │                              ↓
[带回食材 + 宝藏 + 新菜谱] ← [战斗 + 收集]
```

**驱动力**: 钱 ↔ 资源双向流动,养成系统是桥梁

**3 个循环的关系**:
- 餐厅 / 迷宫是**各自独立的小循环**
- 核心循环 = 两个小循环 + 经济 + 养成 → 串成"双向正反馈"
- 关键洞察:**养成 = 跨系统衔接层**,没有它,两个循环是孤立的
