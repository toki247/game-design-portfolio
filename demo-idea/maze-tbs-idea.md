## 世界观(2026-08-21 13:43)

参考**迷宫饭**——故事发生的城市有地下迷宫入口:

1. **迷宫入口**: 城市里有地下迷宫,生存各种魔物 + 潜藏宝藏与秘密
2. **冒险者职业**: 进入迷宫探索,形成专门职业
3. **产业链**: 冒险者击败魔物带出 → 交给**魔物料理餐馆**当食材 + 卖值钱东西 → 餐馆制作魔物料理

> 世界观是骨架,系统设计(战棋 / 黑暗地牢 / 搜打撤 等)是后续展开。

## 主角设定(2026-08-21 14:20)

- **兄妹**: 经营**魔物餐馆**的兄妹(主角就是餐馆老板)
- **动力**: 餐馆需要食材 + 赚钱
- **循环**:
  1. 进迷宫搜索宝藏
  2. 狩猎魔物
  3. 把魔物处理成食材
  4. 在餐馆做成料理
  5. 售卖 → 赚钱 → 进更深迷宫

> 这跟"普通冒险者 → 卖给餐馆"产业链不同 — 主角**就是餐馆经营者**,自己进迷宫找食材。战斗 + 烹饪双线循环。
