# demo idea 终版:三消 + 回合制战斗 + 肉鸽

> W1 终版 · 2026-08-03 凌晨 家里定稿
> 状态:W1 第 1 步"定核心 idea"完成,准备进入 W2 范围

## 核心体验(一句话)

通过三消发动技能,击败敌人并领取奖励,进而强化或改变技能的游戏。
核心体验 = 三消的简单易上手策略性 + 快速爽感,结合肉鸽的随机性和成长感。

## 核心机制

**基础循环**
- 三种颜色方块 = 1 角色的三个技能(每个技能对应一种颜色)
- 消除数量多少定技能效果强度
- 玩家回合固定行动次数,单次消除消耗 1 点,行动次数归 0 切敌方回合,双方循环

**肉鸽层(a+c)**
- (a) 局内随机 build:每局技能池不同
- (c) 局内地图/事件随机:场景变化

**策略性落点**
- 主要在肉鸽玩法上体现:每局 build 组合选择 / 地图与事件路径选择 / 技能强化方向抉择

## 关键决策

- **框架**:框架一(1 角色 3 技能),不选框架二的 combo 联动
- **理由**:保持"简单易上手+快速爽感",避免三层组合爆炸
- **1v1 boss 战 demo**:暂缓(不砍),等想好具体设计再回来
- **作品集关系**:这是"自己想做的游戏",不进入"3D 战斗策划"求职作品集

## 待办(W2 范围要回答)

- 棋盘尺寸(几行几列)
- 行动次数(一回合几次)
- 角色属性(HP / 护甲 / 能量等)
- 技能池大小 + 强化机制
- 敌方种类 + AI 行为
- 肉鸽层具体颗粒度(build 生成规则 / 地图节点类型 / 奖励机制)
