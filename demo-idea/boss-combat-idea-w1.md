## 引导问题 2: 玩家核心动作 / 反馈环(关键决策: 双方血量规则)

### 前置: 双方血量规则(最关键)

"互相过招牵制"必须有"双方血量规则"来支撑。3 选项:

- **A. 双方一击必死**(纯一击必杀) — 玩家和 boss 都是 1 血,1 次攻击命中就结束
  - 战斗变成"谁先出手"的猜拳
  - 反馈环最短(1 击)
  - **风险**: 玩起来像剪刀石头布,缺少"动作"成分
- **B. 玩家一击必死 + boss 多血 3-5**(不对称) — 玩家失误立刻死,boss 有 3-5 血
  - 类似只狼的架势 + 一击致命,但更极端
  - 玩家**必须**找机会反复命中 boss,自己不能挨打
  - **风险**: 玩家压力大,可能觉得不公平
- **C. 双方多血 + 一击重创**(格斗风格) — 玩家和 boss 都有 5+ 血,每次命中都掉大半血
  - 类似武士零的"一击必杀"机制,但加了多回合
  - 数回合结束战斗,每回合都关键
  - **风险**: 反馈环变长,可能不像"一击必杀"

**已定**(2026-08-19 23:52 用户): **C. 双方多血 + 一击重创**

### C 选项的串联逻辑

**1. "互相过招牵制"在 C 下自然成立**:
- 双方都有 5+ 血,任何一击都掉大半血
- 玩家可以**试探攻击**(轻击,30%)— 引诱 boss 出招
- boss 反击 — 玩家要躲/格挡
- 玩家看准时机**重击**(80%)— 致命一击
- 玩家失误/挨打 — 自己也快死
- 数回合决出胜负,**每回合都关键**

**2. 跟武士零最像,但 3D 实时**:
- 武士零是 2D 横版 + 慢动作闪避标记
- 这里是 3D 自由移动 + 实时反应
- 武士零 1 击必死 — 这里是"重创"(几回合)

**3. 3D 战斗的"过招"维度**(比 2D 多):
- 绕背 / 绕侧 — 牵制
- 读招 — boss 攻击前摇,玩家预判
- 格挡 / 闪避 / 翻滚 — 牵制
- 重击前摇 — 风险大,可能挨打

**4. 反常识点(跟传统 1v1 boss 战比)**:
- 没有"耐力"概念(魂系列)
- 没有"架势条"概念(只狼)
- 每次攻击都几乎致命 — "每击都关键",不是"攒伤害"
- 3D 实时 — 反应要求比武士零高

**5. 用户具体化 v2(2026-08-20 00:14)**: **资源循环 + 部位破坏**(去掉"致命"元素,加容错)

### 核心循环: 能量管理 + 部位破坏 + 容错

**结构**(去掉 C 选项的"致命",加入"容错"和"资源循环"):
- 玩家有**容错血量**(多血,可以挨几次打,但会死)— 跟 C 不同的关键
- 玩家有**能量系统**(轻击攒能量 / 蓄力消耗能量)— 资源循环
- 玩家有**部位破坏机制**(蓄力是破部位和打核心的关键)
- boss 有 N 个可破坏部位 + 核心血量(双层血)
- 玩家挨打不会立刻死,但失误太多会死

**战斗循环**:
1. 玩家轻击(扣少量 boss 部位血 + 攒能量)— 牵制 + 资源积累
2. 玩家蓄力(消耗能量 + 高伤害 + 前摇,可能挨打)— 输出
3. 蓄力破部位(部位血 0)— 触发"破部位奖励": **大硬直 + 恢复部分能量**
4. 玩家打核心(需要消耗能量 / 蓄力)— 限时(硬直期间)
5. boss 反击 — 玩家要躲/格挡
6. 重复步骤 1-5,直到核心血 0

**资源循环的串联逻辑**:
- **轻击牵制**: 轻击不只是"打伤害",是"攒能量" + "牵制 boss"
- **蓄力消耗**: 蓄力是"释放能量"的高风险高回报动作
- **部位破坏奖励**: 破部位 → 恢复能量 + 创造输出窗口(大硬直)
- **容错**: 玩家挨打不死,但会扣血;扣血多了死

**互相过招牵制的体现**:
- **轻击的"牵制"**: 玩家在 boss 攻击间隙打轻击,不只是打伤害,是为蓄力做准备
- **蓄力的"过招"**: 玩家蓄力时,自己处于危险(boss 攻击可能打断),boss 也在攻击
- **部位破坏的"奖励"**: 破部位后,大硬直让玩家有输出窗口 + 恢复能量
- **容错的"再战"**: 玩家挨打不死,可以"失误后恢复",但失误太多会死

**反常识强度**:
- 跟怪猎不同: 怪猎是**任何部位都掉总血**,这里是**双层独立血** + **资源循环**
- 跟传统不同: 传统 1v1 boss 战**直接打血条**,这里是**先打外层,才能打内层** + **能量管理**
- 跟武士零不同: 武士零是**1 击必死**,这里是**资源循环 + 容错**
- 3D 实时 + 资源循环 + 部位破坏 — 玩法独特

**对 W2-W5 的影响**:
- W2 范围: 玩家有 2 个攻击模式(轻击/蓄力)+ 1 个能量系统 + 部位破坏机制 + 容错血量
- W3 3C: 角色/相机/控制 跟"轻击节奏"和"蓄力前摇"绑定
- W4 机制清单: 能量系统(最大/恢复/消耗)+ 部位血量 + 核心血量 + 玩家血量 + 蓄力时间 + boss 招式
- W5 路线图: 先做能量系统,再加部位系统,最后加核心机制

## 引导问题 3: 反常识点 / 差异化

**一击必杀已经是一个反常识**(传统 1v1 boss 战都是多血慢节奏),但具体反到什么程度?

**对比标杆**:

| 标杆 | 血量规则 | 节奏 | 关键机制 |
|---|---|---|---|
| 魂系列 | 多血 | 慢 | 翻滚无敌帧 + 耐力 |
| 空洞骑士 | 多血 | 中 | 下劈 + 冲刺 + 多次攻击 |
| 哈迪斯 | 多血 | 快 | 连招 + 神力 + 肉鸽 |
| 怪猎 | 多血 | 中 | 精确判定 + 部位破坏 + 多人 |
| **只狼** | 多血(架势条) | 中 | 完美格挡 + 一击致命(架势满了再一击) |
| **武士零** | 一击必死 | 快 | 闪避 + 慢动作 + 即时反馈 |

**你的反常识点可能是**:
- 比只狼更极端: 每次攻击都致命,没有架势积累 — "打中就赢,没打中就死"
- 比武士零更直接: 没有慢动作时间,纯实时反应
- 完全不同: 回合制猜拳 + 一击必杀(参考 7-01 封印勇者的反常识思路)
- 借鉴怪猎/空洞的**部位破坏**到一击必杀里(如"打中 boss 不同部位触发不同致命效果")

**自检问题**:
- 你的"一击必杀"具体是哪种?(魂?只狼?武士零?还是别的?)
- 你想保留哪个标杆的哪些元素?(如只狼的"架势条"、武士零的"闪避慢动作")
- 你的反常识点是什么?(纯一击必死?有"防御反击"?有没有"血量蓄积"过程?)
