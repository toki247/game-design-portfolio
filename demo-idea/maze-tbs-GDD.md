### 1.4 世界观梗概

- **世界观**: 西幻蒸汽时代，魔法与机械共存的世界；人们会在日常生活中使用魔法驱动机械工具和武器

- **魔导器**: 人们发明了使用魔力锻造的核心，在复杂机器上装在魔力核心可以加速装置内的魔力流转效率、减少损耗。于是通过魔力驱动的魔导器逐渐开始成为主流，遍布人们的生活和生产中

## 2. 核心循环
扮演餐厅的经营者，进入地下城狩猎魔物，并将其带出并处理成食材，制作成料理卖出，获得金钱。金钱用于养成，帮助玩家更好的探索地下城

### 2.1 总核心循环(餐厅 ↔ 迷宫)

```
[餐厅赚钱] ── 投入 ──→ [养成系统](技能 / 装备 / 职业)
     ↑                              ↓
     │                        [进迷宫变强]
     │                              ↓
[带回食材 + 宝藏 + 新菜谱] ← [战斗 + 收集]
```

### 2.2 餐厅循环

```
[库存] → [食谱] → [烹饪] → [售卖] → 钱
   ↑                                    ↓
   └────── [员工系统 / 店铺升级] ←─────┘
```

### 2.3 迷宫循环

```
[进迷宫] → [战斗 + 探索] → [收集 + 掉落] → [撤退 / 继续]
   ↑                                                ↓
   └────── [临时道具 / 祝福(Buff)] ←───────────────┘
```

## 4. 关键机制(MVP)

### MVP 端到端循环

1. 玩家进迷宫
2. 遇到 1 个战斗
3. 赢了带回 1 个食材
4. 回餐厅做菜
5. 卖 1 笔钱

### 战斗(空之轨迹式 — 玩家 4 动作)

| 动作 | 做什么 | 关键点 |
|---|---|---|
| **轻击** | 出手迅速 + dash 位移 + **不伤害** + 攒能量 + 格挡 | 资源循环核心 |
| **蓄力** | 消耗能量 + **唯一伤害源** + 前摇长 + 破坏部位 | 唯一伤害来源 |
| **格挡** | 帧窗口判定 + 反击方向 | boss 攻击时可触发 |
| **位移** | 轻击自带 dash 一段距离 | 跟轻击合并 |

(从 `boss-combat-demo/docs/W1-idea.md` 搬运,用户 8-20 14:09 升级)

### 部位系统(已定)

- **结构**: 4 部位(头 / 躯干 / 腿 1 / 腿 2)+ 1 核心
- **血量**: 双层独立血(部位血 + 核心血)
- **关键破坏 → 核心可打**: 关键部位血 0 → mesh 隐藏 + 核心暴露
- **核心血 0 → 死亡**

### 餐厅(简化 — 6 系统)

- **库存**: 存食材 + 装备 ✅ Inventory autoload
- **食谱**: 食材比例 → 价格 ✅ RecipeBook autoload(3 食谱)
- **烹饪**: 消耗食材 → 菜 ✅ cook.gd(+/- 数量 / ScrollContainer / 弹窗)
- **售卖**: ~~卖菜 → 钱~~ **已整合进烹饪(2026-08-25)** ✅(确认烹饪时直接加金币)
- **店铺升级**: 装修 + 设施 ❌ 待做
- **员工系统**: 优先级下调(2026-08-25)— 先做 P1 战斗最小,后续再回;具体配置待定

### 养成系统(4 子系统 — 跨系统桥梁)

- **技能**: 学习 / 升级(迷宫外)
- **装备**: 获取 / 穿戴 / 强化(迷宫外)
- **道具**: 消耗品 / 临时反馈(迷宫内)
- **职业**: 战斗职业选择(迷宫外)— **无餐馆职业**

## 12. 游戏过程

### MVP 阶段(1 个最小循环)

1. 启动 demo
2. 在餐厅(显示库存 + 食谱)
3. 触发"进迷宫"
4. 进入战棋(1 个战斗)
5. 战斗胜利,带回 1 个食材
6. 回餐厅
7. 用食谱做菜
8. 售卖
9. 获得钱 → 结束 1 循环

### 当前已落地流程(2026-08-25)

**页面层级**:
```
启动 → 主菜单(3 大入口)
     └─ 餐厅(2 子入口)
        ├─ 仓库(3 tab: 食材/装备/重要物品)
        └─ 烹饪(3 食谱, 自动售卖)
```

**已跑通循环**(餐厅子系统内):
- 仓库查看库存(读 Inventory autoload)
- 烹饪选择食谱 + 调数量(上限 = min(各食材库存/需要数))
- 确认 → 扣库存 + 加金币(自动售卖)
- 弹"获得 X 金币" → 弹"结束烹饪?" → 回餐厅页

**未接通**:
- 主菜单 → 地下城(待 P1 战斗 + 迷宫)
- 主菜单 → 养成(待 P4)
- 餐厅 → 主菜单(返回路径,2026-08-25 已加)
