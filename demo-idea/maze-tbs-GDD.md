## 1. 游戏概述

### 1.1 名称 / 平台 / 定位

- **游戏名称**: [待定]
- **运行平台**: PC
- **游戏定位**: 独立游戏 / 中小型

### 1.2 类型 / 风格

- **类型**: 战棋 + 餐厅经营
- **风格**: 2D手绘风格，Q版
- **参考**: 迷宫饭 + 空之轨迹 + 潜水员戴夫

### 1.3 简述

> 玩家扮演一对经营**魔物餐馆的兄妹**,在地下迷宫中搜索宝藏、狩猎魔物,把迷宫带回的魔物处理成食材,在自家餐馆做成料理售卖。通过"餐厅赚钱 → 强化迷宫(技能 / 装备 / 职业)→ 迷宫带回更多"的双向正反馈循环推进。

### 1.4 世界观梗概

- **世界观**: 西幻蒸汽时代，魔法与机械共存的世界；人们会在日常生活中使用魔法驱动机械工具和武器
- **魔力**: 世界运行的本源，作为能量的流通于万事万物之中；古代人们会直接运转魔力释放魔法，或用特定的容器与法阵注入魔力来运行，由此制作成魔法器具和魔法卷轴、陷阱等使用
- **魔导器**: 人们发明了使用魔力锻造的核心，在复杂机器上装在魔力核心可以加速装置内的魔力流转效率、减少损耗。于是通过魔力驱动的魔导器逐渐开始成为主流，遍布人们的生活和生产中
- **迷宫**: 
- **冒险者职业**: 进入迷宫探索,形成产业链(参考迷宫饭)
- **主角身份**: 兄妹就是餐馆老板,自己进迷宫找食材

### 1.5 核心特色

- 战斗 + 烹饪双线循环
- 部位破坏 + 资源循环
- 餐厅 ↔ 迷宫双向正反馈
- 黑暗地狼风险机制(后续)

## 2. 核心循环

### 2.1 总核心循环(餐厅 ↔ 迷宫)

```
[餐厅赚钱] ── 投入 ──→ [养成系统](技能 / 装备 / 职业)
     ↑                              ↓
     │                        [进迷宫变强]
     │                              ↓
[带回食材 + 宝藏 + 新菜谱] ← [战斗 + 收集]
```

### 2.2 餐厅循环

```
[库存] → [食谱] → [烹饪] → [售卖] → 钱
   ↑                                    ↓
   └────── [员工系统 / 店铺升级] ←─────┘
```

### 2.3 迷宫循环

```
[进迷宫] → [战斗 + 探索] → [收集 + 掉落] → [撤退 / 继续]
   ↑                                                ↓
   └────── [临时道具 / 祝福(Buff)] ←───────────────┘
```

## 4. 关键机制(MVP)

### MVP 端到端循环

1. 玩家进迷宫
2. 遇到 1 个战斗
3. 赢了带回 1 个食材
4. 回餐厅做菜
5. 卖 1 笔钱

### 战斗(空之轨迹式 — 玩家 4 动作)

| 动作 | 做什么 | 关键点 |
|---|---|---|
| **轻击** | 出手迅速 + dash 位移 + **不伤害** + 攒能量 + 格挡 | 资源循环核心 |
| **蓄力** | 消耗能量 + **唯一伤害源** + 前摇长 + 破坏部位 | 唯一伤害来源 |
| **格挡** | 帧窗口判定 + 反击方向 | boss 攻击时可触发 |
| **位移** | 轻击自带 dash 一段距离 | 跟轻击合并 |

(从 `boss-combat-demo/docs/W1-idea.md` 搬运,用户 8-20 14:09 升级)

### 部位系统(已定)

- **结构**: 4 部位(头 / 躯干 / 腿 1 / 腿 2)+ 1 核心
- **血量**: 双层独立血(部位血 + 核心血)
- **关键破坏 → 核心可打**: 关键部位血 0 → mesh 隐藏 + 核心暴露
- **核心血 0 → 死亡**

### 餐厅(简化 — 6 系统)

- **库存**: 存食材 + 装备
- **食谱**: 食材比例 → 价格
- **烹饪**: 消耗食材 → 菜
- **售卖**: 卖菜 → 钱
- **店铺升级**: 装修 + 设施
- **员工系统(优先级最高)**: [待定](玩家配置员工提高效率,具体配置什么待定)

### 养成系统(4 子系统 — 跨系统桥梁)

- **技能**: 学习 / 升级(迷宫外)
- **装备**: 获取 / 穿戴 / 强化(迷宫外)
- **道具**: 消耗品 / 临时反馈(迷宫内)
- **职业**: 战斗职业选择(迷宫外)— **无餐馆职业**
