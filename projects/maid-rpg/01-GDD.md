## 3. 核心玩法

- **回合制战斗 + 3 槽装备构筑**
- 女仆可以改装手部、腿部、核心三个模块的武装
- 改装后形成 **27 种不同战斗构筑**(3 核心 × 3 手部 × 3 腿部)

## 4. 核心循环

> ⚠️ **本节为推导稿**(2026-10-26 从第 4 / 5 / 6 / 10 步的设计反推),不是最初就定下来的。**需确认后定稿** —— 核心循环一旦定错,后面四层全部要返工。

### 4.1 战斗内循环(秒级)

```
行动条推进(每 0.2s tick)
  → 满条单位行动(并列时玩家优先)
  → 结算(受击六步管线:闪避/招架 → 扣穿透算有效防御 → 减伤率 → 破防 ×1.5 → 护盾吸收 → 累积韧性)
  → buff/debuff 状态变化(DOT 周期触发)
  → 回到行动条
```

### 4.2 战斗间循环(分钟级)

```
接敌
  → 选构筑(核心 × 手部 × 腿部 = 27 种)
  → 战斗内循环
  → 胜负判定(胜 / 败 / 逃)
  → 战果结算(经验 / 掉落)
  → 升级 +3 属性点(自由分配)
  → 改装(换构筑 / 换改装件)
  → 回到接敌
```

### 4.3 章节循环(小时级)

```
探索(调查 / 潜行 / boss rush)
  → 收集线索
  → 解锁改装件(店主教 / 潜行改件 / 防御程序)
  → 推进章节
  → 改变结局走向(全线索 / 部分线索 / 无线索)
```

### 4.4 三层循环的分工

| 层级 | 玩家在做什么 | 对应的设计层 |
|---|---|---|
| 秒级 | 选指令、算伤害、赌时机 | 系统设计(战斗) |
| 分钟级 | 配构筑、分配属性点 | 系统设计(构筑 / 养成)+ 内容设计(模块) |
| 小时级 | 探图、收集线索、选结局 | 关卡设计 + 内容设计(剧情) |

> **设计意图**:三层循环的爽点不同 —— 秒级靠操作与计算,分钟级靠构筑搭配,小时级靠信息收集与叙事反转。三层互相不能抢戏,这是「内容设计」要平衡的东西。
