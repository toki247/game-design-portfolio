- **回合制战斗 + 3 槽装备构筑**
- 女仆可以改装手部、腿部、核心三个模块的武装

## 4. 核心循环

> ✅ **已定稿**(2026-10-27 确认)。本节只回答三件事:**玩家反复在做什么、每次得到什么反馈、为什么要重复**。
> 流程细节不在这里重复 —— 战斗内流程见 `02-系统设计.md` §1.5,章节流程见 `04-关卡设计.md` §2。

### 4.1 一句话

**在 1-2 小时的探索里反复「配一套构筑 → 拿它打一场 → 用战果把它变强 → 换下一套构筑」,直到够格打最终 BOSS。**

三层是套在一起的,不是三段并列的流程:

```
小时级(章节)   探索找线索 · 解锁新手段  ──►  决定这一章能用什么构筑
      ▼
分钟级(战斗间) 选构筑 · 分配属性点        ──►  决定下一场打得顺不顺
      ▼
秒级(战斗内)   出招 · 赌时机              ──►  决定这一场能不能赢
      ▲
      └────────  战果回流(经验 / 掉落)  ────────┘
```

### 4.2 三层循环

| 层级 | 反复做的动作 | 每次的反馈 | 为什么愿意重复 |
|---|---|---|---|
| **秒级 · 战斗内** | 行动条轮到我时选指令:打哪一招 / 改用技能 / 开强击 / 逃 | 立刻结算 —— 伤害、破防、状态变化、对手的下一手 | 每回合都是一次独立的小赌注,赢不赢我心里有数 |
| **分钟级 · 战斗间** | 用战果配出下一场要用的构筑,分配属性点 | 变强看得见,但也看得见自己的构筑被哪类敌人克 | 27 种构筑的搭配空间大,每次换装都是一次新尝试 |
| **小时级 · 章节** | 在地图上找线索、解锁改装件、推进主线 | 线索本身就是奖励,而且它决定结局走向 | 情报越齐可选的路越多 —— 但时间只有 1-2 小时 |

**三层不能互相抢戏**:
- 秒级靠**操作与计算**,分钟级靠**搭配**,小时级靠**信息**。
- 如果战斗里的每个选择都能靠构筑强度碾过去,秒级就废了。
- 如果线索只影响结局、不影响战斗,小时级就废了。

### 4.3 关键决策点

只列 GDD 层面的决策点,细则都在 02 / 04:

| 决策 | 细则在哪 |
|---|---|
| 行动条轮到玩家 → 选指令(攻击 / 技能 / 逃跑) | `02` §1.5 10.1 |
| **开强击模式 = 战斗内的主动指令**,与出招同级 | `02` §1.8 强击核心 |
| 敌人轮到 → AI 选招(规则简单优先,跑起来再细化) | `02` §1.5 10.4 |
| 胜负判定 → 战果结算 | `02` §1.5 10.2 / 10.3.1 |
| **改装 = 章节节点解锁 + 战斗中随时可换已解锁的** | `02` §4 / `04` §2 |
| **战斗失败 = 回到战斗前的地图状态,重打本场**;线索与已解锁改装件保留,不掉级不丢装备 | `02` §1.4 失败出口 |
| 线索 → 防御程序 → 结局分支 | `02` §7 / `04` §2 章节 3 |

### 4.4 三条自洽性约束

改设计时拿这三条验一遍,防止破坏核心循环:

1. **强击 5 回合硬上限是规则不是配置** —— 任何构筑、任何模块都不能延长它(已定 4 / 5)。
2. **行动速度与战斗速度量纲分离** —— 战斗速度拉满不会让你先动手,行动速度拉满也不会提高闪避(已定 15)。
3. **属性点总量不能盖过构筑差异** —— 否则「防御拉满」变成万能解,27 种构筑的设计就废了(`05` §3 风险提示)。
