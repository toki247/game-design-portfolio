### S2 · 属性公式层

| 项 | 内容 |
|---|---|
| **目标** | 5 属性 + 行动速度 → 全部派生值算出来 |
| **依赖** | S1 |
| **产出** | `core/stats_calc.gd` |
| **完成标准** | 给定 5 属性(体格/力量/速度/技巧/幸运)+ 行动速度,输出 HP/攻击/防御/行动条速度/闪避率/暴击率/减伤率/招架率,全部对得上 02-系统设计.md 1.9 公式表 |

**公式表**(02-系统设计.md 1.9):
```
HP          = 体格 × 2
攻击力      = 力量 + 武器攻击 + buff
防御        = 体格
行动条速度  = 行动速度 × 2
闪避率      = (幸运 + 速度) / 2 向上取整
暴击率      = (技巧 + 幸运) / 2
减伤率      = 有效防御 / (有效防御 + K)     ← K 走 config
招架率      = 闪避率 + 减伤率                ← 武士刀核心
```
⚠️ K 值未定(数值调试阶段),配置里先留 `K = 100` 占位

### S3 · 战斗容器 + 行动条

| 项 | 内容 |
|---|---|
| **目标** | 行动条循环跑起来,能看出谁先动 |
| **依赖** | S2 |
| **产出** | `core/battle_state.gd` + `core/action_gauge.gd` |
| **完成标准** | 放 2 个假单位(不同行动速度),能打印出行动顺序;行动速度 100 约 5 秒一次行动;并列时玩家先动 |

**核心逻辑**(02-系统设计.md 1.5):
```
每 0.2s(tick):
  所有单位 action_gauge += (行动速度 × 2) × 0.2
  找出 action_gauge >= 1000 的单位
  若多个 → 玩家优先
  → 该单位行动
  → action_gauge = 0(溢出清零)
```

**验收自查点**:
- 溢出清零后,会不会出现「两个单位永远差一点点到 1000」的死循环?
- 行动速度 0 的单位(被减速 debuff)要不要设跑速下限 1?

### S4 · 伤害结算管线

| 项 | 内容 |
|---|---|
| **目标** | 一次受击的完整结算跑通 |
| **依赖** | S2 + S3 |
| **产出** | `core/damage_pipeline.gd` |
| **完成标准** | 输入攻击方技能 + 防御方状态,输出最终扣血量;含破防 / 护盾 / 防御穿透三种情况 |

**六步管线**(02-系统设计.md 1.9,顺序已确认):
```
1. 判定闪避 / 招架        → 命中则继续,未命中直接返回 0
2. 扣防御穿透 → 有效防御 = max(0, 防御 - 穿透)
3. 减伤率 = 有效防御 / (有效防御 + K) → 最终承伤
4. 判定破防(韧性打空)     → × 1.5
5. 护盾优先吸收 → 溢出扣 HP
6. 累积韧性
```

⚠️ **DOT 结算时机未定**(裂伤/流血)—— 挂在这块一起定

### S6 · 三核心运行时

| 项 | 内容 |
|---|---|
| **目标** | 三个核心各自跑通资源循环 |
| **依赖** | S5 |
| **产出** | `core/core_runtime/core_base.gd` + 三个子类 |
| **完成标准** | 火力能量槽增减正常;暗杀爆发状态开启/延长正常;强击切换→5 回合→强制终结技→状态回滚正常 |

**强击 runtime 的关键路径**(02-系统设计.md 已定 4/5,最复杂的一个):
```
切换强击
  → 记录进模式前状态(血量上限/血量)
  → 应用模块代价(枪炮无 / 双刀减半上限 / 武士刀锁 1 点血 + 10 层身外身)
  → remaining_turns = 5,每 tick -1
  → 第 5 回合末 → 强制释放终结技
  → 结算终结技(枪炮按伤害回血 / 双刀回满+恢复上限 / 武士刀耗刚剑+按身外身回血)
  → 统一回滚临时状态
```
⚠️ 武士刀退出血量 = `max(身外身剩余层数 × 10%, 1)`

| 溢出清零后死循环 | 两个单位行动条永远差一点点到 1000 | 检查是不是清了没重算,或者 tick 精度问题 |
| tick 精度 | 0.2s 累积有浮点误差 | 用固定累加器,不要用 `delta` 直接乘 |
| 0.2 秒太频繁 | 一场战斗几百次 tick,日志刷屏 | 加个 debug 开关,只在行动时才打印 |
| 行动速度 0 卡死 | 被减速的单位永远不动 | 跑速设下限 1 |
