## 第 4 步:机制清单

### 4.1 核心机制 — 27 构筑

**3 模块 × 3 选项**:

| 模块 | 选项 | 作用 |
|---|---|---|
| **核心** | 火力 / 暗杀 / 强击 | 改变战斗循环(能量循环方式) |
| **手部** | 枪炮 / 双刀 / 武士刀 | 攻击输出方式(普通 + 爆发技能) |
| **腿部** | 喷射 / 光学 / 不动 | 防御方式(被动特性) |

- 每个手部模块都有"普通 + 爆发"(武士刀 **3 个**技能:普通 + 蓄能 + 拔刀斩)
- 每个腿部模块都有"模块特性(固定)+ 核心增幅(随核心)"

### 4.2 战斗系统

- **FF7 行动条式战斗**:满行动条可进行 1 次动作
- **韧性机制**(双方都有):见下方完整规则
- **护盾系统**:见下方完整规则

#### 韧性机制(2026-10-21 补全)

**积累**

- 受击时,根据**招式的冲击力倍率**累积韧性
- 每个招式自带 `基础冲击力倍率`(见 Skill 数据结构),倍率越高累积越快
- 韧性有**上限**,且**每个单位上限不同**(主角 / 各敌人 / boss 各有自己的韧性上限)

**破防**

- 韧性条打空 → **破防** → 受伤害 **+50%**
- 破防后**持续 1 回合**:该回合内受到的伤害持续 +50%

**恢复**

- 破防的**下一回合**恢复**全部韧性条**(回到满值)
- 恢复时直接回满,不做部分恢复

> 循环节奏:打空 → 1 回合增伤窗口 → 回满 → 再打空。这让韧性成为「双方轮流找窗口」的攻防节奏工具。

#### 护盾系统(2026-10-21 新增)

- 护盾是**临时生命值**:优先承受伤害,打穿后溢出部分才扣到本体 HP
- 护盾**会被击破**(不是永久增益)
- 护盾**不影响韧性和减伤效果** —— 护盾吸收伤害,不等于完全免伤,不阻断韧性累积
- **护盾上限 = 当前最大生命值**(即最多只能挡满一整条血)
- 光学装置是当前唯一提供护盾的模块(见 8.6),护盾**不跨回合叠加**(已定 9)

> 护盾 / 韧性 / 减伤是三套独立机制,分别管「血量缓冲 / 破防窗口 / 数值减免」,互不干扰。

### 4.3 3 核心 — 资源循环

| 核心 | 能量槽 | 资源获得 | 消耗 → 效果 |
|---|---|---|---|
| **火力** | 300 | 普通攻击 | 消耗释放手/腿爆发(**动作型,一次性**) |
| **暗杀** | 500 | 闪避 / 暴击 | 满槽开启**爆发状态**(攻击 ×1.2,基础 5 回合,延长:触发 1/3/5/7/9 次闪暴 → +1 回合) |
| **强击** | 无固定槽 | **挨打换伤害**(被动减伤 / 回血累积) | 主动切换**强击模式**(各模块自定义血量代价 + 加成),用**终结技**退出 |

### 4.4 强击核心详细机制(2026-10-21 改版)

**核心定位**:**通过挨打来换伤害** —— 承担更高风险,兑现更高输出。装备强击核心后,战斗中**获得一个主动技能用于切换强击模式**,由玩家自己判断时机。

> ⚠️ **本节已作废**:原「护盾抵消伤害 → 充能池 → 满池进强击模式 → 充能耗完退出」循环(旧 charge_pool / shield 机制)全部作废。
> 新版:强击模式改为**主动切换**,不再有全局充能池。风险来源从「被动充能」改为「自伤 / 减上限 / 减防」等**各模块自定义代价**。

#### 通用结构

- **进入方式**:战斗开始时获得 1 个**主动技能**(切换为强击模式),玩家自行决定何时开
- **进入代价**:各手部模块自定义(自伤 / 减生命上限 / 减防等)
- **强击模式内收益**:各模块自定义(伤害倍率提升 / 吸收效率翻倍 / 按剩余血量提升属性等)
- **退出方式**:各模块自定义终结技,打完回到普通模式

#### 硬性规则 — 强击模式回合上限 5 回合

**强击模式最多持续 5 回合,不可延长。**

- 第 5 回合结束时**强制释放终结技**,打完立即退出
- **终结技是强击模式的唯一出口**,不存在"未放终结技就退普通模式"的情况
- 终结技效果结算完毕后,统一回滚所有强击期间的临时状态(详见 8.7「已定 5」)
- 回合上限**不因模块不同而变化**,3 个手部统一 5 回合
- 设计意图:强制玩家在有限窗口内做决策 —— 什么时候开、开到第几回合放终结技;同时保证临时状态不会泄漏到普通模式

#### 设计意图

让「挨打」成为**玩家主动选择的风险**,而不是被动充能攒满就开。挨得越多收益越高,但进入强击模式本身就要先付出代价 —— 风险与收益的兑换关系由玩家在战斗中自己权衡。

### 4.4.1 强击核心三套实现范式

三个手部走出三条不同的路:

| | 枪炮模块 | 双刀模块 | 武士刀模块 |
|---|---|---|---|
| 血量代价 | 技能 1 每次扣 20% 最大生命 | 释放刀扣 20% 最大生命 / 进强击减半上限 | 进强击**生命值变 1 点** + 10 层身外身免伤 |
| 防御向代价 | 强击模式防 **-50%** | 进强击 **30% 减伤** | **放弃闪避**(闪避率转招架率) |
| 强击内收益 | **背水**:按剩余血量比例提升攻/冲/暴 | 吸收效率 100% + 释放额外伤害 100% | **【刚剑】**叠层:每层 +10% 攻/冲 +1% 招架,最多 10 层 |
| 挨打怎么变现 | 掉血 → 被动减伤阶梯上升 | 挨打 → 吸收回血 | 招架 → 叠刚剑;未招架 → 化身外身免伤 |
| 终结技 | 全体 200% + 按造成伤害回血 | 单体 300% + 回满血 | 耗尽刚剑(每层 +15% 攻/冲 +2% 破甲)+ 按身外身层数回血 |
| 退出后血量 | 保留终结技回血后的值 | 回满血 | **身外身剩余层数 × 10%**(最低 1 点,不判死)—— 层数用得越多出来越残 |
| 定位 | 越残血越强的**赌命输出** | 用血量管理换**续航 + 高爆发** | 用招架次数换**成长 + 破甲处决**,但额度烧完就残 |

**三种范式分别对应**:枪炮 = 高风险高波动(喜欢刀尖跳舞),双刀 = 血线管理(稳扎稳打),武士刀 = 招架叠层(靠操作和技术流吃收益)。

> ⚠️ **注意**:
> - 「防御 -50%」原以为是**强击核心通用加成**,现确认是**枪炮模块专属**(跟双刀的 30% 减伤、武士刀的放弃闪避并列,不是通用规则)。三个模块代价不同向,构筑才有区分度。
> - 武士刀的「生命值变 1 点」最极端 —— 但靠 10 层【身外身】兜底,实际是「限定 10 次挨打额度」,不是裸送。

**共用硬性规则**:强击模式**最多 5 回合**,到点强制退出(详见 4.4「硬性规则」)。三条范式的终结技都必须在这 5 回合内打出。

### 4.5 数值框架

**5 属性**:体格 / 力量 / 速度 / 技巧 / 幸运

**基础公式**:

| 数值 | 公式 |
|---|---|
| HP | 体格 × 2 |
| 攻击力 | 力量 + 武器攻击 + buff |
| 防御 | 体格 |
| 行动条速度 | 速度 × 2 |
| 闪避率 | (幸运 + 速度) / 2(向上取整) |
| 暴击率 | 技巧 + 幸运 / 2 |
| 暴击伤害 | × 1.5 |
| 命中率 | 技巧 - 对方闪避 |
| 冲击力 | 招式伤害 × 招式冲击力倍率(见 Skill.impact_multiplier) |
| 屏障最大值 | 防御 × 5 |

**受击结算公式**:

| 结算项 | 公式 |
|---|---|
| **减伤率** | **防御 / (防御 + K)**,K 为配置常量(待定) |
| 招架率 | 闪避率 + 减伤率(已定 7) |
| 最终承伤 | 原始伤害 × (1 - 减伤率) × (破防 ? 1.5 : 1.0) |
| 护盾吸收 | min(最终承伤, 护盾 current),溢出部分扣 HP |
| 韧性累积 | 招式冲击力 × 招式冲击力倍率 × 韧性系数 |

**结算顺序**(已确认):
1. 判定闪避 / 招架(武士刀)
2. **扣除防御穿透** → 计算有效防御
3. 计算减伤率 → 得出最终承伤
4. 判定破防(韧性是否打空)→ ×1.5
5. 护盾优先吸收 → 溢出扣 HP
6. 累积韧性

#### 防御穿透的实现方式(2026-10-21 定)

**防御穿透 = 攻击时直接扣减目标的有效防御数值,再进减伤率公式。**

```
有效防御 = max(0, 目标防御 - 穿透值)
减伤率   = 有效防御 / (有效防御 + K)
```

- 穿透**不是独立乘区**,是**减法扣防御值**
- 减到 0 为止(不产生负值),`max(0, ...)` 兜底
- 影响链条:穿透 ↑ → 有效防御 ↓ → 减伤率 ↓ → 承伤 ↑

> 注意:因为常数除法有递减收益,**低防御段减同样的防御值收益更大** —— 高防角色被穿透时的减伤跌幅会比低防角色明显。这符合直觉(防得高的人,被破防时掉得也狠)。

> ⚠️ **副作用**:减伤率同时是招架率的一半来源(`招架率 = 闪避率 + 减伤率`)。武士刀终结技有 `+2% 防御穿透`/层,**但这是攻击方的穿透,不作用于自己**,因此不与自己的招架率冲突。

**K 值的作用**:决定「多少防御算好」的手感基准。常数除法里,`防御 = K` 时正好承伤 50%。K 本身走配置(已定 10),数值调试时再调。

#### 减伤公式的选型(2026-10-21 定)

**采用常数除法:`减伤率 = 防御 / (防御 + K)`**

**为什么选这个**(对比另外两种常见做法):

| 方案 | 公式 | 特点 |
|---|---|---|
| **FF7 原作** | `Damage ∝ (512 - Defense)` | 固定基数减法,防御有硬上限(512 归零) |
| **常数除法(采用)** | `防御 / (防御 + K)` | 递减收益,天然不超 100%,低防区收益高 |
| 固定百分比减伤 | 直接给 `% 减伤` | 不走曲线,每点更值,但难跟防御属性挂钩 |

**选常数除法的三个理由**:

1. **跟韧性 / 招架率咬合更好** —— 招架率 = 闪避率 + 减伤率,需要能堆到较高百分比的量。常数除法直接产出百分比且有明确上限(趋近但不到 100%)。
2. **避免防御穿透算出负伤** —— 武士刀终结技有 `+2% 防御穿透`/层。FF7 那种固定基数减法被打穿容易算出负数需要额外 clamp,常数除法永远落在 0~1。
3. **跟双档增幅结构兼容** —— 强击模式防 -50% 在**乘区**上做(`defense_mult = 0.5`)比在固定值上做干净。

> 参考:
> - FF7 原作固定基数公式 `Damage = Power × (512 - Defense) × BaseDamage / (16 × 512)` —— [Final Fantasy Wiki - Damage](https://ffwiki.finalfantasy.com/index.php/Damage)
> - 现代 RPG 常见常数除法,例:Star Savior PVE `DefenceConst = 3000` —— [GachaWiki 伤害公式](https://gachawiki.info/guides/star-savior/blog/damage-formula-and-stat-optimization-guide);银与血 `K = 1300`,DEF 1300 → 承伤 50% —— [GachaWiki 防御公式](https://gachawiki.info/guides/silver-and-blood/blog/defense-formulas)

> ⚠️ **仍待补的数值**:
> - **K 值**(常数除法的平衡核心,待数值调试)
> - 背水 = g(剩余血量比例) —— 见 8.5 枪炮
> - 韧性系数(冲击力 → 韧性值的换算比)
> - 韧性上限的具体数值(每单位不同,需逐个配置)
> - 招架率上限 / 是否独立乘区

## 第 7 步:数据结构

### 设计原则

1. **手部特性归属火力核心** — 枪炮 OVERHEAT / 双刀 ARMOR_PIERCE / 武士刀 CHARGE 只在**火力核心**下生效,作为火力核心的被动机制成组出现。**暗杀 / 强击核心不额外设计手部特性**,手部模块在这些核心下只有技能。
2. **腿部:特性固定 + 增幅按核心** — 3 个腿部模块各带 1 条固定被动(所有核心共用),核心增幅因核心而异。
3. **核心增幅 = 因核心不同**
4. 手部:**技能**因核心而异(每个核心的技能设计不同)
5. 核心增幅可以是**主动技能**(有 CD)
6. 强击模式可**主动退出**(释放技能 1/2 是退出动作)

### Module

```
Module {
  part_type: HAND | LEG
  
  name, visual, description
  
  // 手部:技能因核心而异
  skills_by_core: {
    fire: [Skill, ...],
    assassin: [Skill, ...],
    strong: [Skill, ...]
  }
  
  // 手部特性:只在火力核心下生效(暗杀 / 强击为空)
  hand_feature_by_core: {
    fire: ModuleFeature?,        // OVERHEAT / ARMOR_PIERCE / CHARGE
    assassin: null,
    strong: null
  }
  
  // 腿部固定被动:所有核心共用
  leg_feature: PassiveFeature?
  
  // 核心增幅:每个核心独立
  core_amp_by_core: {
    fire: CoreAmp?,
    assassin: CoreAmp?,
    strong: CoreAmp?
  }
}
```

> 腿部被动优先级:**固定特性**(恒生效)⊕ **核心增幅**(按核心,可主动/被动)
> 手部在暗杀 / 强击核心下**无特性**,只有技能。

### ModuleFeature(手部特性 — 仅火力核心)

只在**火力核心**下生效;暗杀 / 强击核心下手部模块无特性。

| 类型 | 对应模块 | 关键字段 |
|---|---|---|
| OVERHEAT | 枪炮 | thresholds, decay_per_turn, overload_state |
| ARMOR_PIERCE | 双刀 | base_pierce, burst_pierce, burst_status |
| CHARGE | 武士刀 | charge_skill_id, release_skill_id, charge_buff |

### PassiveFeature(腿部被动)

```
{
  trigger: 每 N 回合 | 进入战斗时 | 持续 | ...
  effect: {
    target: SELF | ENEMY | ALLY,
    stat: SPEED | DEFENSE | ACCURACY | EVASION | ...,
    mode: ADD | MULTIPLY | OVERRIDE,
    value: number,
    duration: 永久 | N 回合 | 触发型
  }
}
```

### CoreAmp(核心增幅,可主动或被动)

```
{
  type: PASSIVE | ACTIVE
  trigger: "每消耗 X 能量" | "主动释放" | "受到伤害" | "常驻"
  cooldown: int  // 仅 ACTIVE 有(光学装置护盾用)
  // ⚠️ 强击核心的腿部增幅是「双档」(已定 8):normal 一套,strong_mode 一套
  tiers: {
    normal: { ... }       // 普通模式参数
    strong_mode: { ... }  // 强击模式内参数(数值更强)
  }
  // 其他核心仍用单一参数
  effect: { ... }
}
```

### Skill

```
{
  type: NORMAL | BURST
  name, energy_cost,
  damage_multipliers[],     // 基础倍率(如 180% / 300%)
  impact_multiplier,        // 基础冲击力倍率(决定受击方累积多少韧性)
  aoe_targets, energy_gain_per_use,
  effects: [StatusEffect]
}
```

> `impact_multiplier` 是韧性系统的输入项(见 4.2)—— 招式设计时必须同时考虑伤害倍率和冲击力倍率。

### BuffDebuff(增益 / 减益 —— 通用结构)

```
{
  type: OVERHEAT | MIND_EYE | SHEATH | BURST_STATE | STRONG_MODE | WOUND | HEAVY_WOUND
      | SWORD_INTENT | HASTE | RECOVERY | SMOKE
      | PARRY | HARD_EDGE | DECAY(崩解) | OUTSIDE_BODY | SHIELD | BACKWATER(背水) | ...,
  // 数值增减
  target: SELF | ENEMY | ALLY
  stat: ATTACK | IMPACT | CRIT_RATE | PARRY_RATE | DEFENSE | DAMAGE_RECEIVED | ...,
  mode: ADD | MULTIPLY | OVERRIDE,
  value: number,
  // 层数(可选)
  max_stacks: int,
  current_stacks: int,
  // 持续(可选;不填 = 永久,直到战斗结束)
  duration: int,   // 回合
  decay_per_turn: number
}
```

**设计原则**:
- 所有数值型增减走同一个 BuffDebuff 结构,不按用途分叉
- 需要层数的加 `max_stacks` / `current_stacks`,不需要就留空
- 需要时限的加 `duration`,永久的留空

**已用到的 buff / debuff**:

| 效果 | 类型 | 层数 | 归属 |
|---|---|---|---|
| **招架率** PARRY | 属性(SELF) | — | 强击武士刀(闪避率 + 减伤率转换) |
| **【刚剑】** HARD_EDGE | 增益 | 最多 10,每层 +10% 攻/冲 +1% 招架 | 强击武士刀 |
| **【崩解】** DECAY | 减益 | **1,不叠层**,重复只刷新时长 | 强击武士刀 |
| **【身外身】** OUTSIDE_BODY | 免伤额度 | 10,每受 1 次未招架攻击 -1 层 | 强击武士刀 |
| **护盾** SHIELD | 特殊(独立结构) | 上限 = 当前最大生命值,不叠加 | 强击光学装置 |
| **背水** BACKWATER | 增益(比例) | — | 强击枪炮(按剩余血量) |

> **【崩解】不叠层**:同目标只存 1 层(8.7 已定 6)。
> **招架率公式**:`招架率 = 闪避率 + 防御减伤率`,具体公式待 4.5 补(8.7 已定 7)。
> **护盾**走独立的 `Shield` 结构(见下),不用 BuffDebuff —— 因为它有独立的吸收逻辑。

### Tenacity(韧性)

```
{
  current: float,
  max: float                 // 每个单位上限不同(主角 / 敌人 / boss 各自配置)
  broken: bool,               // 是否处于破防状态
  broken_turns_remaining: int // 破防持续回合(1 回合 → 受伤害 +50%)
}
```

- 受击时按招式 `impact_multiplier` 累积 current
- 打空 → broken = true,持续 1 回合
- 下一回合恢复 max

### Shield(护盾)

```
{
  current: float,
  max: float        // = 当前最大生命值(双刀减半上限时会跟着变)
  cooldown: int     // 光学装置:普通 3 回合 / 强击 2 回合
  source: ...       // 来源模块
}
```

- 优先吸收伤害,溢出才扣 HP
- **不叠加**:已有护盾时不刷新、不追加
- **不影响韧性累积和减伤计算**
- 上限 = 当前最大生命值

### Character

```
{
  // 5 属性 + 公式算出
  hp, attack, defense, action_speed, evasion, crit_rate, accuracy
  
  core: Core(FIRE / ASSASSIN / STRONG)
  hand: Module
  leg: Module
  
  // 战斗状态
  current_hp, current_energy
  current_max_hp,              // 可被临时修改(双刀减半 / 武士刀 1 点锁定)
  shield: Shield               // 护盾(可为 null)
  tenacity: Tenacity           // 韧性
  buffs: [BuffDebuff]          // 增益 / 减益
  module_state: { overheat, bleed_stacks, sheath_ready, ... }
  action_gauge: float
}
```

### Enemy

```
{
  name, level
  hp, attack, defense, action_speed, evasion
  skills: [Skill]               // 每个 Skill 含 impact_multiplier
  current_max_hp, current_hp
  shield: Shield               // 可为 null
  tenacity: Tenacity           // 上限按敌人类型配置(杂兵 / 精英 / boss 不同)
  buffs: [BuffDebuff]
}
```

### Core(每个核心字段不同,不复用)

```
Core (FIRE) {
  type: FIRE
  energy_capacity: 300
  current_energy: int
  // 无额外状态字段(机制通过 Skill 触发)
}

Core (ASSASSIN) {
  type: ASSASSIN
  energy_capacity: 500
  current_energy: int
  burst_state: {
    active: bool,
    remaining_turns: int,    // 基础 5,可延长
    modifier: { attack_mult: 1.2, ... }
  }
}

Core (STRONG) {
  type: STRONG
  // ⚠️ 2026-10-21 改版:不再有 charge_pool / shield,改为「主动切换 + 各模块自定义代价」
  // 旧结构 charge_pool / shield 已作废,详见 8.7「已定 2」
  strong_mode: {
    active: bool
    enter_cost: ...           // 各模块自定义(枪炮: 无固定代价,靠技能自伤 / 双刀: 上限减半)
    mods: { ... }             // 各模块自定义(枪炮背水 / 双刀吸放 100%)
    exit_skill_id: int        // 强击模式终结技
    damage_accumulated: float // 枪炮终结技按期间伤害回血用
  }
  // 临时生命上限(双刀减半用),需要支持 max_hp_modifier
  max_hp_modifier: { value: float, source: ... }
}
```

## 第 8 步:模块设计(18/18 完成)

### 8.1 火力核心 × 手部

#### 枪炮模块(左手机枪 + 右手榴弹炮)

- **特性**:OVERHEAT
  - 连续攻击积攒过热条
  - 33% / 66% 阈值提升攻击力
  - 每回合衰减 50%
  - 100% 过载 → 强制冷却 1 回合

- **技能**:
  - 技能 1 - 连续射击:3 次 × 40% 攻击伤害,核心能量积蓄 50 点/次
  - 技能 2 - 榴弹打击:AOE 80% 攻击伤害,核心能量积蓄 40 点/人
  - 爆发 - 全弹发射:消耗 200 能量,机枪 5 次 × 50% + 榴弹 200% AOE,不积蓄能量

#### 双刀模块(双手激光切割刀)

- **特性**:ARMOR_PIERCE
  - 自带 15% 无视防御

- **技能**:
  - 技能 1 - 连续挥砍:2 次 × 75% 攻击伤害,核心能量积蓄 60 点/次
  - 技能 2 - 横斩:AOE 最多 3 个,80% 攻击伤害,核心能量积蓄 50 点/人
  - 爆发 - 激光强化:消耗 150 能量,无视防御 40%,附加裂伤(2 回合叠 5 层,30% 攻击伤害/回合)

#### 武士刀模块(左手刀鞘 + 右手武士刀)

- **特性**:CHARGE
  - 蓄能(技能 2)→ 心眼(50% 减伤)
  - 拔刀斩(爆发)效果因核心而异

- **技能**:
  - 技能 1 - 挥砍:120% 攻击伤害,核心能量积蓄 100 点/次
  - 技能 2 - 蓄能(入鞘):消耗 80 能量,本回合心眼(50% 减伤)
  - 爆发 - 拔刀斩:无消耗(需入鞘),300% 攻击伤害,积蓄 60 能量;击杀 → +100 能量 + 心眼

### 8.5 强击核心 × 手部(2/3 完成)

> 强击核心 = 「挨打换伤害」:承担更高风险,兑现更高输出。装备强击核心后获得**主动切换技能**,玩家自己判断时机开。
> 设计约束:手部模块**不额外设计被动特性**(特性归火力核心,见第 7 步设计原则),强击核心的手部设计围绕**血量代价 + 强击内收益 + 终结技退出**三件套。

#### 枪炮模块(电磁炮 + 紧急维生护盾)

**被动 — 紧急维生护盾**

根据当前剩余生命值百分比提供阶梯减伤:

| 生命值 | 减伤率 |
|---|---|
| 80% | 20% |
| 60% | 40% |
| 40% | 60% |
| 20% | 80% |

> 血量既是输出资源,也是生存资源 —— 越残越抗打。

**普通模式**

- **技能 1 — 电磁炮**:消耗 20% 最大生命值,造成攻击力 **180%** 伤害

**强击模式**

- **被动 — 背水**:根据剩余生命值比例提升攻击力 / 冲击力 / 暴击率(比例待定)
- **防御 -50%**:强击模式下受到伤害提高 50%
- **技能 1**:不再消耗生命值,伤害倍率提升至 **200%**,冲击力 **+50%**
- **强击模式终结**:对敌方全体造成攻击力 **200%** 伤害,并根据强击模式期间造成的伤害按比例恢复生命值

#### 双刀模块(能量吸收刀 + 能量释放刀)

**被动(普通 + 强击模式共用一套,参数随模式变)**

- **能量吸收刀**:攻击敌人时,将造成伤害的 **20%** 转化为自身生命值
- **能量释放刀**:攻击敌人时,消耗当前**最大生命值的 20%**,造成 **30%** 额外伤害

**普通模式**

- **技能 1 — 能量吸收刀**:造成攻击力 **120%** 伤害
- **技能 2 — 能量释放刀**:造成攻击力 **120%** 伤害

**强击模式**

- **进入代价**:当前生命上限减半,获得 **30%** 减伤
- **被动增强**:吸收效率提升至 **100%**;释放刀额外伤害提升至 **100%**
- **强击模式终结**:双刀斩击,造成攻击力 **300%** 伤害并恢复满生命值,之后恢复原本的生命值上限

> 吸收 / 释放 = 同一套刀的两种形态,普通模式是「回血 + 破防」,强击模式是「满吸 + 重炮」。

#### 武士刀模块(武士刀 + 反击刀鞘)

**被动 — 反击刀鞘(仅强击模式生效)**

强击模式下的武士刀**无法进行闪避**,但会把**闪避率**和**防御减伤率**转化为**招架率**。

- **招架率 = 闪避率 + 防御力带来的减伤率**(两项相加;具体公式见 8.7「已定 7」)
- 每次受到伤害时判定招架
- **触发招架** → 免疫本次伤害,并获得 1 层【刚剑】
- **【刚剑】**:每层提升 **10% 攻击力 + 10% 冲击力 + 1% 招架率**,最多 **10 层**

> 用「放弃闪避 + 集中防御」换「招架 + 攻击成长」—— 不靠残血,靠挨打次数堆叠输出。堆防御也能堆招架。

**普通模式**

- **技能 1 — 招架准备**:提升本回合 **20% 招架率**;敌方攻击被招架时进行反击,造成 **50%** 攻击力伤害
  - 若反击攻击的敌人带有【崩解】→ 消耗【崩解】,造成额外 **80%** 伤害
- **技能 2 — 崩解**:攻击并施加【崩解】,造成 **100%** 攻击力伤害

**强击模式**

- **进入代价**:将自身生命值变为 **1 点**,招架率 **+20%**;获得 **10 层【身外身】**
- **【身外身】**:每当受到**未被招架**的攻击时,失去 1 层并**免疫本次伤害**(最多 10 层)
- **被动增强**:
  - 招架攻击时**自动为敌人附加【崩解】**
  - 反击攻击倍率提升至 **80%**
  - 消耗【崩解】造成的额外伤害提升至 **150%**
- **强击模式终结**:消耗全部【刚剑】造成攻击力 **100%** 的伤害
  - 每层【刚剑】提升本次攻击 **+15% 攻击力 + 15% 冲击力 + 2% 防御穿透**
  - 根据剩余【身外身】层数回复生命值,每层恢复 **10%**(最大生命值),**最低保留 1 点**
  - ⚠️ **退出后血量就保持为这个值,不还原进模式前的血量** —— 挨打消耗的身外身越多,出来保留的血量越少;层数烧光也不死,只剩 1 点(详见 8.7「已定 5 · 武士刀血量规则」)

> 1 点血 + 10 层身外身 = 硬性 10 次免伤额度;挨满再终结技按层数回血 —— 把「被打」直接换算成「回血 + 破甲爆发」,但额度用光就出来残血。

### 8.6 强击核心 × 腿部(3/3 完成)

> 腿部 = 固定被动特性(所有核心共用)+ 核心增幅(按核心)。
> 强击增幅全部对齐「挨打换伤害」主线,且**三项都是双档**:普通模式一套、强击模式内更强的一套(其余两个核心的腿部增幅没有这个双档结构)。

#### 喷射装置

- **特性**(固定):每 3 回合 +2 速度,最多 +10
- **核心增幅**(强击 · 普通):攻击造成的冲击力 **+10%**,受到攻击时受到的冲击力 **-10%**
- **核心增幅**(强击 · 强击模式):攻击造成的冲击力 **+20%**,受到攻击时受到的冲击力 **-20%**

> 冲击力双向调整 —— 打别人更快破防,自己更难被破。属于「节奏控制」向。

#### 光学装置

- **特性**(固定):降低敌人命中率 / 闪避率 10%
- **核心增幅**(强击 · 普通):受到伤害时获得**最大生命值 20%** 的护盾,**冷却 3 回合**
- **核心增幅**(强击 · 强击模式,2026-10-21 改版):**【光学蓄能】** —— 受到伤害时获得 1 层,**最多 10 层**;每层提升攻击力 **2%**(层数在战斗结束后清空)

> ⚠️ **为何改版**(见 9.4 构筑验证):强击模式下的护盾增幅跟手部机制全面冲突 ——
> - **#23 双刀 + 光学**:双刀进强击上限减半,护盾上限 = 当前最大生命值(= 减半后),等于**双重血量惩罚**;功能还跟双刀自身的「吸收回血」重复。
> - **#26 武士刀 + 光学**:护盾吸收伤害 → **挨打次数减少** → 身外身 / 刚剑攒不满,**与手部核心机制直接对立**。
>
> **改版思路**:强击核心的手部全部自带防御向机制(阶梯减伤 / 30% 减伤 / 1 点血免伤),腿部再给防御就撞车。改给**攻击向**后,光学从「减伤向」补位成「输出向」,与手部形成互补。
>
> **普通模式保留护盾**:火力 / 暗杀核心下护盾增幅没有问题(那些手部不吃防御),只改强击。

> 【光学蓄能】是叠层 buff,不叠加数值外的其他效果 —— 每层独立计,满 10 层 = 攻击力 +20%。**战斗结束清零**(同不动装置的持有型叠层)。

#### 不动装置

- **特性**(固定):+20% 防御 / -20% 受冲击力
- **核心增幅**(强击 · 普通):受到攻击时,防御力 **+2**,最多 **+10**
- **核心增幅**(强击 · 强击模式):受到攻击时,防御力 **+3**,最多 **+15**

> 挨打叠防御 —— 防御对武士刀直接换算招架率,对枪炮部分抵消强击的防 -50%。
> **叠层为「持有型」**:受到攻击后永久生效直到战斗结束,**每场战斗清零**。

#### 三套强击腿部增幅速查

| 腿部 | 普通模式 | 强击模式内 | 挂钩点 | 定位 |
|---|---|---|---|---|
| 喷射 | 冲击 +10% / 受冲击 -10% | 冲击 +20% / 受冲击 -20% | 常驻 | 节奏控制(破防能力) |
| 光学 | 受伤给 20% HP 护盾,CD 3 | **【光学蓄能】受伤 +1 层,最多 10 层,每层 +2% 攻击** | 挨打叠层 | **攻击成长**(2026-10-21 改版) |
| 不动 | 受伤 +2 防,上限 +10 | 受伤 +3 防,上限 +15 | 挨打叠层 | 防御成长(抗压) |

**设计取向**:三套都挂「挨打 / 常驻」,没有一条是攒资源换爆发的(火力/暗杀那种)—— 呼应强击核心「挨打换伤害」的定位。

**光学装置在强击下改为攻击向**(2026-10-21,见 9.4):强击模式不再给护盾,改为【光学蓄能】叠攻击。这是「防御向 → 攻击向」的位置补位,让腿部能给强击核心补输出,而不是跟手部抢防御池。

**跟手部的配合关系**:
- **不动装置 + 武士刀**:防御 → 招架率,是最直接的搭档
- **光学装置 + 枪炮 / 双刀 / 武士刀**:挨打叠攻击,补强击核心的输出(不再抢防御)
- **喷射装置 + 任意**:双档冲击,通用破防

**三条实现规则已定**(见 8.7「已定 9」):普通模式的光学护盾**不叠加**;不动装置防御加成为**持有型**(挨打后永久生效至战斗结束);不动装置叠层**每场清零**。**【光学蓄能】同样是持有型叠层,每场清零**。

**所有数值支持配置**(见 8.7「已定 10」):倍率 / 层数 / CD / 上限 / 公式常量全部走 Resource 配置,不硬编码。

## 8.7 特性归属 & 数据结构决议

### 已定 1 — 手部特性归属火力核心

**手部模块的「特性」(OVERHEAT / ARMOR_PIERCE / CHARGE)只在火力核心下生效**,暗杀和强击核心**不额外设计手部特性**。

- 手部特性 = 火力核心专属的被动机制,随火力核心一起成组出现
- 暗杀 / 强击核心下手部模块只有**技能**(按核心各不相同),没有额外被动
- 数据结构落法:`Module` 不再有跨核心的特性字段,特性挂在核心侧或按核心分支存放

### 已定 2 — 强击核心改为「主动切换 + 血量代价」(2026-10-21 改版)

- ⚠️ **旧版 charge_pool 方案作废**:`charge_pool { current, max }`(max=800)删掉,不再有全局充能池。
- 强击模式改为**战斗中获得主动切换技能**,玩家自己判断时机开,不靠被动充能攒满。
- 风险来源从「被动充能」改为**各模块自定义血量代价**(自伤 / 减上限 / 减防)。
- 退出靠**各模块的「强击模式终结」技能**,不再是"充能耗完自动退出"。
- 理由:让「挨打」成为玩家主动选择的风险,而不是被动攒满就开 —— 风险与收益的兑换由玩家在战斗中自行权衡。
- 数据结构落法见下方「待定 — STRONG 新结构」。

### 已定 3 — 强击手部只有技能,无独立特性

- 枪炮的「紧急维生护盾」和双刀的「吸收 / 释放刀」**不算通用 ModuleFeature**,是强击核心下手部模块自带的被动形态,不进 `hand_feature_by_core` 结构。
- 武士刀的「反击刀鞘」(闪避转招架 + 叠刚剑)同理,是强击核心下手部模块的专属被动形态。
- 沿用已定 1 的原则:手部在强击核心下只有「技能 + 模块自带被动」,无跨核心特性字段。

### 已定 4 — 强击模式硬性 5 回合上限(2026-10-21)

- 强击模式**最多 5 回合**,不可延长,不因模块不同而变化。
- 第 5 回合结束**强制释放终结技**,打完立即退出。
- **不存在"未放终结技就退普通模式"的情况** —— 终结技是强击模式的必经出口,不是可选。
- 终结技放完后**一并回滚**所有强击期间的临时状态(见已定 5)。
- 理由:强制玩家在有限窗口内决策(何时开 / 第几回合放终结技),避免苟着不放导致强度无限累积;同时保证强击期间的临时状态不会泄漏到普通模式。

### 已定 5 — 到期强制释放终结技 + 状态回滚(2026-10-21,含武士刀血量规则修订)

- **5 回合到期 → 系统自动释放终结技 → 立即回滚临时状态**。
- 终结技是强击模式的**唯一出口**,无论玩家主动放还是系统代放,效果一致。
- 回滚清单(终结技效果结算完毕后统一清空):
  | 临时状态 | 归属 | 回滚方式 |
  |---|---|---|
  | 减半生命上限 | 双刀 | 还原到进模式前数值 |
  | 生命值锁定 1 点 | 武士刀 | **解锁,血量保持为终结技结算后的值**(见下方武士刀规则) |
  | 【身外身】层数 | 武士刀 | 清空(已用于计算回血) |
  | 【刚剑】层数 | 武士刀 | 清空(终结技已消耗) |
  | 防御 -50% / 30% 减伤 | 枪炮 / 双刀 | 移除 modifier |
  | 背水 / 吸放增强 / 招架率+20% | 三模块 | 移除 modifier |

#### 武士刀血量规则 — 由【身外身】层数决定

**强击模式退出后保留的血量 = 剩余【身外身】层数 × 10%(最大生命值),最低保留 1 点。**

- **不还原**进模式前的血量 —— 进模式前的血量不参与回滚计算
- 强击期间挨打掉多少,出来的血量就是对应的身外身层数换算值
- **层数消耗越多 → 出来保留的血量越少** —— 这是武士刀强击模式的核心风险敞口
- **存活下限**:身外身层数耗尽(0 层)时退出强击模式,**不会死亡**,最低保留 **1 点**生命值
- 例:10 层全满 → 退出时回满 100%;剩 6 层 → 退出时保留 60%;层数耗尽 → 保留 1 点

> 设计意图:【身外身】是「用挨打换免伤」的额度,而额度用光 = 出来血少 —— 挨得越多,免伤用得越多,但出来后越残。跟枪炮「越残越强」、双刀「减半上限」形成第三种风险形态。
>
> **为什么不设硬死亡**:武士刀强击模式的代价应该是「出来残血」,不是「进去就赌死」。1 点血只是「随时可能被打死」的心理压力,真正的惩罚是层数烧光后只剩 1 点 —— 下一场战斗开局几乎裸血。死亡交给后续战斗判定,不在终结技这里强制发生。

### 已定 6 — 【崩解】为一次性标记,不叠层(2026-10-21)

- 【崩解】**不叠层**,同一目标身上只存 1 层。
- 重复施加(技能 2 再次命中 / 强击模式招架自动附加)**刷新持续时间,不叠层**。
- 触发额外伤害后**立即消耗**,目标身上【崩解】清空。
- 理由:【崩解】是「施加 → 消费」的单一标记,叠层会让反击的额外伤害变成无限增长,失去控制感。

### 已定 7 — 招架率 = 闪避率 + 防御减伤率(2026-10-21)

- **招架率 = 闪避率 + 防御力带来的减伤率**(两项相加)。
- 强击模式下武士刀**放弃闪避**(闪避率不再生效于闪避判定),转而计入招架率。
- 理由:让「堆防御」在强击武士刀身上变成一条可用的构筑路线 —— 高防 = 高招架 = 高刚剑层数。
- ⚠️ **具体公式后续处理**(第 4.5 数值框架阶段补):
  - 闪避率部分:直接取 `(幸运 + 速度) / 2`(向上取整),或需换算成百分比
  - 防御减伤率部分:防御 = 体格,减伤率公式待定(4.5 目前没有「防御 → 减伤率」的换算式,需新增)
  - 最终招架率是否有上限 / 是否需要独立乘区,待数值调试时定

### 待定 — STRONG 新数据结构

旧版结构(`energy_capacity` + `charge_pool` + `shield` + `strong_mode`)需要重写。新版大致方向:

```
Core (STRONG) {
  type: STRONG
  strong_mode: {
    active: bool
    remaining_turns: int      // 硬性 5,不可延长(已定 4)
    enter_skill_id: int       // 主动切换技能
    enter_cost: ...           // 各模块自定义(枪炮: 无固定代价,靠技能自伤 / 双刀: 上限减半 / 武士刀: 生命值 1 点)
    mods: { ... }             // 各模块自定义(枪炮背水+防-50% / 双刀吸放 100% / 武士刀招架体系)
    exit_skill_id: int        // 强击模式终结
    damage_accumulated: float // 枪炮终结技回血用
  }
  // 临时生命上限(双刀减半用),需要支持 max_hp_modifier
  max_hp_modifier: { value: float, source: ... }
  // 武士刀专用:生命值锁定为 1 + 身外身免伤额度
  hp_lock: {
    value: int,             // 1 点血
    source: ...
    // 注意:退出时不还原进模式前血量,血量 = 身外身剩余层数 × 10%(已定 5)
    // hp_before / hp_ratio_before 字段已不需要
  }
  outside_body_stacks: int                     // 身外身,进模式时 10,退出清空(血量已按层数换算)

}
```

> **退出流程**(已定 4 + 已定 5):
> 1. 5 回合到期 或 玩家主动释放 → 强制触发 `exit_skill_id`
> 2. 结算终结技效果(枪炮回血 / 双刀回满血 + 恢复上限 / 武士刀耗刚剑 + 按身外身回血)
> 3. 统一回滚临时状态:清 hp_lock、清 outside_body / hard_edge、移除所有 mods
> 4. `active = false`
>
> 具体字段待 8.6 腿部设计完成后一并定稿。

### 已定 8 — 强击腿部增幅为「双档」结构(2026-10-21)

- 强击核心的腿部增幅**全部是双档**:普通模式一套数值,**强击模式内自动切到更强的一套**。
- 这与其他两个核心不同 —— 火力 / 暗杀的腿部增幅是「攒够资源 → 换一次爆发」,强击没有资源槽,改用「进强击 → 增幅整体变强」。
- 数据结构落法:`core_amp_by_core.strong` 需要支持 `normal` / `strong_mode` 两套参数,而不是单一数值。
- 三套增幅全部挂钩「挨打」或「常驻」,没有一条是攒资源型 —— 呼应强击核心「挨打换伤害」的定位。

### 已定 9 — 强击腿部三条实现规则(2026-10-21)

1. **光学护盾不叠加** —— 护盾**不可跨回合叠加**,冷却结束后才可再次触发;已有护盾时不刷新、不追加。
2. **不动装置防御加成为持有型** —— 「受到攻击时 +2/+3」是**受到攻击后永久生效**(直到战斗结束),不是判定时临时生效。
3. **不动装置防御加成每场清零** —— 战斗结束后叠层归零,不跨战斗保留。

> 由此确定 8.6 的三条实现层待定全部关闭。

### 已定 10 — 所有数值支持配置(2026-10-21)

- **所有战斗数值(倍率 / 层数 / 阈值 / CD / 上限 / 公式常量)必须支持外部配置**,不硬编码在逻辑代码里。
- 落法建议:Godot `Resource` 承载数值配置(`.tres` 文件),逻辑只读配置不写死数值 —— 沿用「数据 Resource + @export」的做法。
- 目的:
  - 数值调试期不用改代码、不用重编译
  - 后续做平衡性调整 / 不同难度档位只需改配置
  - 27 构筑 × 3 核心的数值量很大,硬编码后期维护成本高
- ⚠️ 需在实现层明确:哪些是「配置项」,哪些是「结构逻辑」(如 5 回合上限、双档切换规则这类规则本身应该是代码,不是配置)。

### 已定 11 — 减伤公式采用常数除法(2026-10-21)

- **减伤率 = 防御 / (防御 + K)**,K 为配置常量(按已定 10 走 Resource 配置,数值待调)。
- 选型对比与理由见 4.5「减伤公式的选型」—— 三点理由:跟招架率咬合 / 避免防御穿透负伤 / 兼容双档乘区。
- `防御 = K` 时承伤正好 50%,K 即「多少防御算好」的手感基准。
- K 的取值待数值调试阶段定,不影响现在写代码。

### 已定 12 — 韧性 / 护盾 / buff-debuff 三套底层规则(2026-10-21)

**韧性机制**
- 受击时按招式的 `impact_multiplier` 累积韧性,倍率越高累积越快
- **韧性上限按单位配置**(主角 / 杂兵 / 精英 / boss 各不同)
- 打空 → 破防 → **持续 1 回合受伤害 +50%**
- 破防的**下一回合恢复全部韧性**(直接回满)
- 招式数据结构必须含 `impact_multiplier`(见 Skill)

**护盾系统**
- 护盾 = **临时生命值**,优先承伤,溢出扣本体 HP
- 护盾**会被击破**
- **不影响韧性累积和减伤效果** —— 吸收伤害 ≠ 完全免伤
- **上限 = 当前最大生命值**(双刀减半上限时跟着变)
- 走独立的 `Shield` 结构,不用 BuffDebuff

**buff / debuff 定位**
- **异常状态**(DOT / 硬控 / 异常抗性)—— 暂不做
- **buff / debuff**(数值增减 + 层数 + 持续回合)—— **需要实现**
- 统一走 `BuffDebuff` 结构,不按用途分叉

### 已定 13 — 防御穿透 = 减法扣防御值 + 受击结算顺序确认(2026-10-21)

- **防御穿透的实现**:攻击时扣减目标有效防御值,再进减伤率公式 —— **不是独立乘区**。
  ```
  有效防御 = max(0, 目标防御 - 穿透值)
  减伤率   = 有效防御 / (有效防御 + K)
  ```
- **受击结算顺序已确认**:闪避/招架判定 → 扣防御穿透算有效防御 → 减伤率 → 承伤 → 破防判定 ×1.5 → 护盾吸收 → 累积韧性。
- 副作用提醒:常数除法递减收益意味着**低防段减同样防御值收益更大**,高防角色被穿透时减伤跌幅更明显(符合直觉)。
- 武士刀终结技的 `+2% 防御穿透`/层 是**攻击方穿透**,不作用于自己,与自己招架率不冲突。
