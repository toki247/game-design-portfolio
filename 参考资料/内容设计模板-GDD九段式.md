## 一、设计首页

| 区域 | 内容 |
|---|---|
| 项目一句话 | 玩家身份 + 核心动作 + 目标 + 主要阻力 |
| 游玩条件 | 玩家、平台、输入、单局时长、单人/多人 |
| 玩家承诺 | 最有辨识度的能动性与代价 |
| 支柱(2-4条) | 各带一个反例,能拒绝功能 |
| 核心动词 | 实际输入或高频认知动作 |
| 循环一句话 | 行动如何改变状态并引出下一次选择 |
| 范围 | 当前要证明什么、明确不做什么 |
| 关键结论 | 已裁决的设计决定 |

## 二、玩法走读

60-120秒连续游玩片段,覆盖:进入时目标→第一眼信息→一次核心输入→一次需要比较的选择→选择的代价→系统如何改变局面→一次小成功/失败/恢复。

## 三、核心机制

### 3.1 基础规则
- 核心操作与判定规则
- 胜负条件
- 资源/状态定义

### 3.2 进阶系统
- 成长/升级/解锁
- 经济/积分
- 特殊机制(如事件、buff、连击)

### 3.3 难度与节奏
- 难度曲线
- 关卡/波次设计
- 动态难度(如有)

## 四、内容系统

### 4.1 角色/单位
- 名单与属性
- 稀有度/分类
- 台词/性格

### 4.2 关卡/场景
- 关卡列表
- 场景主题
- 障碍物/互动元素

### 4.3 道具/装备
- 道具列表
- 获取方式
- 使用效果

## 五、界面规划

### 5.1 界面清单
列出所有界面(主界面、游戏界面、结算、设置、图鉴等)

### 5.2 关键界面线框
每个界面标注:信息层级、操作区域、反馈区域

### 5.3 HUD设计
游戏中实时显示的信息(血量、分数、倒计时等)

## 六、音效与音乐

- 音效清单(操作、反馈、事件)
- 语音/台词(如有)

- 材质与质感
